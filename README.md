# 🚀 Практические задания по C#: Деструкторы, Сборка Мусора и IDisposable

Репозиторий содержит решения **40 учебных практических задач** на языке C# (.NET 8.0), посвящённых управлению памятью, работе деструкторов (финализаторов), механизмам сборщика мусора (`Garbage Collector`), реализации интерфейса `IDisposable`, стандартному шаблону Dispose и безопасным дескрипторам (`SafeHandle`).

Проект спроектирован просто, понятно и доступно для начинающих: без переусложнённых абстракций, с наглядными комментариями и интерактивным консольным меню для запуска каждого задания.

## 📋 Список выполненных заданий

1. **Простой деструктор** — класс `Student` с полем `Name` и деструктором `~Student()`.

5. **Деструктор телефона** — класс `Phone` с полями `Brand` и `Model`.
6. **Несколько объектов** — создание 5 объектов `Student` и наблюдение за вызовами финализаторов при `GC.Collect()`.
7. **Метод создания объектов** — метод `CreateProduct()`, возвращающий новый экземпляр `Product`.
8. **Объект внутри метода** — создание `TestObject` в локальной области видимости метода и его сборка.
9. **Деструктор с идентификатором** — класс `Employee` с полем `Id`, вывод ID в финализаторе.
10. **Количество объектов** — класс `Counter`, статический счётчик `ObjectCount` с инкрементом в конструкторе и декрементом в деструкторе.
11. **Управление ресурсом** — класс `FileManager`, имитация файла с автоматическим освобождением в финализаторе.
12. **Деструктор и метод** — класс `Printer` с методом `Print()` и деструктором.
13. **Массив объектов** — создание массива из 10 объектов `Device`, зануление ссылок и сборка мусора.
14. **Циклическое создание объектов** — генерация 20 объектов `Person` в цикле `for` с последующим вызовом GC.
15. **Деструктор с несколькими полями** — класс `BankAccount` (номер, владелец, баланс).
16. **Журнал объектов** — класс `LogObject`, фиксация точного времени удаления в консоли.
17. **Сравнение объектов** — класс `Animal`, исследование недетерминированного порядка финализации объектов одного поколения.
18. **Большое количество объектов** — создание 100 объектов `DataObject` и подсчёт собранных экземпляров.
19. **Деструктор и GC.Collect()** — связка `GC.Collect()` и `GC.WaitForPendingFinalizers()`.
20. **Определение момента очистки** — класс `ObjectTracker`, эксперимент с задержкой между потерей ссылки и срабатыванием GC.
21. **Деструктор и GC.SuppressFinalize()** — демонстрация отмены вызова деструктора при штатном вызове `Dispose()`.
22. **Реализация IDisposable** — класс `ResourceManager`, реализующий ручной метод `Dispose()`.
23. **Паттерн Dispose** — класс `DatabaseConnection` с каноническим шаблоном `Dispose(bool disposing)`.
24. **Освобождение ресурсов** — класс `FileResource` с поддержкой как ручного `Dispose()`, так и финализации.
25. **Деструктор и наследование** — классы `Device` и `Computer`, порядок срабатывания (потомок -> предок).
26. **Порядок деструкторов** — цепочка `Animal` → `Mammal` → `Dog`, демонстрация вызова деструкторов снизу вверх.
27. **Несколько ресурсов** — класс `ResourceHolder`, освобождение нескольких разнородных ресурсов.
28. **Защита от повторного освобождения** — класс `SafeResource` с флагом `_disposed`.
29. **Деструктор и исключения** — использование `using` для гарантированного вызова `Dispose()` при возникновении сбоев.
30. **Деструктор и using** — подтверждение того, что блок `using` подавляет лишний вызов деструктора.
31. **Собственный менеджер ресурсов** — класс `ResourceManager`, хранящий список ресурсов и очищающий их пачкой.
32. **Работа с файловым потоком** — класс `FileHandler` с реальным `FileStream` и корректным закрытием.
33. **Работа с подключением к БД** — класс `DatabaseManager`, имитация пула соединений и разрыва связи.
34. **Иерархия ресурсов** — `Resource` → `FileResource` → `NetworkResource` с каскадным `base.Dispose(disposing)`.
35. **Деструктор и сборка мусора** — сравнение объектов с деструктором и без (попадание в очередь `freachable`).
36. **Анализ производительности** — замер времени сборки 10 000 объектов с помощью `Stopwatch`.
37. **Имитация системного ресурса** — класс `SystemResource` с неуправляемым указателем `IntPtr`.
38. **SafeHandle** — класс `SimpleSafeHandle` на базе `SafeHandleZeroOrMinusOneIsInvalid`.
39. **Полный шаблон освобождения ресурсов** — класс `AdvancedResource` с разделением управляемых и неуправляемых ресурсов.
40. **Итоговый проект — менеджер ресурсов** — архитектурное консольное приложение с регистрацией, отслеживанием, повторной защитой и полиморфной очисткой ресурсов.

## 🛠 Запуск и использование

1. Клонируйте репозиторий или откройте папку проекта:
   ```bash
   git clone https://github.com/mrarlander-boop/DestructorTasks.git
   ```

   ```bash

   ```

## 📚 Глоссарий для новичка

* **`public` / `private` / `protected`** — модификаторы доступа. `public` открывает элемент для всех, `private` ограничивает доступ только внутри текущего класса, `protected` открывает доступ классу и его наследникам.
* **`class`** — шаблон/чертёж для создания объектов.
* **`new`** — оператор выделения памяти в управляемой куче и вызова конструктора.
* **`static`** — признак принадлежности метода или поля всему классу, а не отдельному экземпляру.
* **`void`** — метод, который ничего не возвращает.
* **`this`** — ссылка на текущий экземпляр класса.
* **`base`** — ссылка на базовый (родительский) класс.
* **`IntPtr`** — тип данных для хранения адреса памяти или системного дескриптора (хэндла).
* **`~ClassName()`** — деструктор (финализатор), вызываемый сборщиком мусора перед освобождением памяти объекта.
* **`IDisposable` & `Dispose()`** — интерфейс и метод для явного своевременного освобождения ресурсов программистом.
* **`using`** — конструкция, гарантирующая вызов `Dispose()` при выходе из блока.
* **`GC.Collect()`** — принудительный запуск сборщика мусора.
* **`GC.WaitForPendingFinalizers()`** — ожидание завершения работы фонового потока финализации.
* **`GC.SuppressFinalize(this)`** — отмена вызова финализатора для объекта, ресурсы которого уже были очищены в `Dispose()`.
* **`try-catch-finally`** — обработка исключений и гарантированное выполнение блока финализации.
* **`Stopwatch`** — класс для высокоточного измерения времени выполнения операций.
* **`SafeHandle`** — надёжная системная обёртка вокруг дескрипторов ОС, защищённая от сбоев.
